> **Maîtrisez votre clavier. Accélérez votre avenir.**

HARISS est une plateforme web professionnelle de dactylographie et d'entraînement à la vitesse de frappe. Conçue pour dépasser les standards de Monkeytype, ZType, TypeRacer et Nitro Type, elle offre une expérience utilisateur premium avec des fonctionnalités avancées et un design futuriste.

## ✨ Fonctionnalités

### 🎮 Modes de Jeu
- **Mode Standard** - Entraînement classique avec texte aléatoire
- **Mode ZType** - Mots qui tombent avec système de combo et niveaux
- **Mode Survie** - Vitesse infinie (en développement)
- **Mode Course** - Compétition multi-joueurs (en développement)
- **Mode Défi** - Objectifs quotidiens (en développement)

### 📊 Statistiques Avancées
- WPM (Mots par Minute)
- CPM (Caractères par Minute)
- Précision en temps réel
- Temps de réaction
- Heatmap du clavier
- Historique complet des performances
- Graphiques de progression

### 🏆 Système de Progression
- Niveaux et XP
- Succès et Badges
- Certificats (Débutant à Expert)
- Classements Mondial, National, Hebdomadaire
- Récompenses et Déblocages

### 🤖 Intelligence Artificielle
- Analyse automatique des erreurs
- Détection des touches faibles
- Génération d'exercices personnalisés
- Recommandations adaptatives

### 🎨 Design Premium
- Interface ultra-moderne et minimaliste
- Dark Mode par défaut
- Effets Glassmorphism et Neumorphism
- Animations 60 FPS
- Dégradés électriques (bleu, violet, cyan)
- Design inspiré d'Apple, Stripe et Linear

### 🔐 Sécurité & Authentification
- Inscription/Connexion sécurisée
- JWT (JSON Web Tokens)
- Protection XSS et CSRF
- Rate Limiting
- Hash bcrypt
- Connexion Google et GitHub (prévu)

### 🌐 Internationalisation
- Interface entièrement en français
- Support de multiples langues (anglais, espagnol, allemand)
- Dispositions de clavier : AZERTY, QWERTY, QWERTZ, DVORAK

## 🛠️ Stack Technique

### Frontend
- **HTML5** - Structure sémantique
- **CSS3** - Styles modernes avec animations
- **JavaScript ES6+** - Logique métier
- **Canvas API** - Animations et jeux (particules, ZType)
- **Web Audio API** - Effets sonores

### Backend (Prévu)
- **Node.js** - Runtime JavaScript
- **Express** - Framework web
- **MongoDB** - Base de données NoSQL
- **JWT** - Authentification
- **LocalStorage / SessionStorage** - Stockage client

### Architecture
- MVC (Modèle-Vue-Contrôleur)
- API RESTful
- Code modulaire et commenté
